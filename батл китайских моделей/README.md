# Батл китайских моделей — Hungry Fish

Октябрь 2026. GLM-5.3, DeepSeek V4 Pro и Kimi K3 получают одно и то же
текстовое техзадание и сами, без человека, строят по нему браузерную
3D-игру Hungry Fish: маленькая рыба ест добычу мельче себя, растёт и в
финале проглатывает военный крейсер. Игру модель пишет, проверяет и
публикует на Vercel сама. Для сравнения те же ТЗ получил Claude Opus 5.5
на уровнях effort low и high. Отдельно идёт прогон новой Kimi K3.1 Pro.

Эталон, с которым сравнивались игры, — версия, собранная на Opus 5.5 с
правками автора (24.09.2026): https://fable-eta-neon.vercel.app

## Условия

- **Изоляция.** Каждая модель работает отдельным агентом в своём
  контейнере Docker. В рабочей папке лежат только файлы ТЗ. Других
  реализаций, заметок и прошлых прогонов модель не видит.
- **Один агент на всех.** Все модели подключены к Claude Code напрямую
  через Anthropic-совместимый API своего провайдера (z.ai, DeepSeek,
  Moonshot), без OpenRouter. Рассуждения на максимум, контекст 1M. Opus 5.5
  работает по подписке Claude с указанным уровнем effort.
- **Промпт и ТЗ слово в слово.** Все модели одной серии получили один и тот же
  промпт и одни и те же файлы. Тексты лежат в этой папке.
- **Без подсказок по игре.** Когда работа обрывалась (лимит запросов
  провайдера, истёкший вход), агент получал одну фразу «Продолжай с того
  места, где остановился, до полного выполнения задачи по исходным
  условиям». Других сообщений было два:
  - в серии 1 у всех трёх моделей истёк токен Vercel. Это ошибка стенда, а
    не моделей: после замены токена агенты получили сообщение, что токен
    обновлён, и просьбу опубликовать игру;
  - GLM-5.3 в серии 3 после финиша один раз доработал игру по замечанию
    автора «не видно рыбы игрока».

## Что здесь

| Файл | Что это |
|---|---|
| `GAME_DESCRIPTION.md` | описание игры: правила, баланс, персонажи, противники, управление, интерфейс. Одинаковое во всех сериях |
| `WORLD_QUALITY_v1.md` | требования к игровому миру, версия 1: биомы, атмосфера, наполнение, живость, звук, камера |
| `WORLD_QUALITY_v2.md` | требования к миру, версия 2: стартовый кадр в метрах, процентах яркости и цветах, отладочный интерфейс `window.__HF`, приёмка по восьми скриншотам |
| `промпт-серия-1.md` | промпт серии 1 |
| `промпт-серии-2-и-3.md` | промпт серий 2 и 3 |

Агент получал требования к миру под именем `WORLD_QUALITY.md`, так его
называет промпт. Версия в имени добавлена только здесь, чтобы два файла
не путались. `{PROJECT}` в промпте — имя рабочей папки и проекта на
Vercel, например `hungry-fish-kimi-v2`.

## Как повторить у себя

1. Создайте пустую папку и положите в неё `GAME_DESCRIPTION.md`, а для
   серий 2 и 3 ещё нужную версию требований к миру под именем
   `WORLD_QUALITY.md`.
2. Нужны Node.js, npm, git и Vercel CLI, токен Vercel — в переменной
   окружения `VERCEL_TOKEN`.
3. Дайте агенту промпт своей серии, заменив `{PROJECT}` на имя папки.
   Дальше агент работает сам: пишет игру, проверяет её, публикует и
   записывает адрес в `DEPLOY_URL.txt`, а отчёт — в `REPORT.md`.
