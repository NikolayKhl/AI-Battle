## Как повторить у себя

1. Заведите тестовый amoCRM и интеграцию с долгосрочным токеном
   (`4-инструкция-amocrm.md`). Создайте в сделках поля «Менеджер»,
   «Источник заявки», «Причина проигрыша» и впишите их id в
   `стенд/fields.json` по образцу `fields.example.json`.
2. Рядом со скриптами — `env.sh` с тремя строками: `AMO_SUBDOMAIN`,
   `AMO_TOKEN`, `AMO_PIPELINE_ID` (в git не кладите).
3. `python3 стенд/fill_crm.py --new-pipeline` — воронка; `--fill` — сорок
   сделок с контактами, полями, задачами, перепиской и звонками.
4. Дайте своему агенту `3-техзадание-для-нейросети.md`, стандарт и файл
   доступа. Вердикты он пишет в карточки примечанием
   `АУДИТ <ИМЯ>` — формат в ТЗ.
5. `python3 стенд/диспетчер.py приёмка` — сверка вердиктов из карточек с
   эталоном; `счётчик` — сколько карточек заполнено; `цена` — рубли по
   прайсу из `расход.json` агента.

Нужен только Python 3, сторонних библиотек нет. Имена клиентов и
менеджеров синтетические; стандарт и проверка настоящие.
