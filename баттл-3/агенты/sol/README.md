# Контролёр SOL

Запуск одной сделки:

```bash
./run.sh D-09
```

Запуск выбранных сделок:

```bash
./run.sh D-17 D-33 D-40 D-12 D-24
```

Полный прогон:

```bash
./run.sh --all
```

Безопасная проверка доступа и структуры без модели и без записи в CRM:

```bash
./run.sh --check
```

По умолчанию используется `gpt-5.6-sol` через Codex CLI по подписке.
Переопределение: `SOL_MODEL=...`; параллельность: `SOL_WORKERS=...`.
Контролёр передаёт CLI только обезличенные данные и сохраняет точный текст
каждого запроса в `обезличенные_запросы.jsonl`. Локальная таблица замен лежит
в игнорируемой Git папке `private/` с правами только владельца.
