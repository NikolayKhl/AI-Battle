# План контролёра SOL

1. **Загрузка.** Python-контролёр при каждом запуске читает `../доступ.txt` и
   `../СТАНДАРТ.md`, через API amoCRM выбирает указанные сделки нужной воронки и
   собирает их поля, стадию, ответственного, задачи, примечания, чаты, звонки и
   доступные расшифровки. Секреты остаются вне кода и вывода.
2. **Подготовка доказательств.** Все события сводятся в хронологию. Имена,
   телефоны и почты локально заменяются устойчивыми метками; таблица замен не
   покидает сервер. Для проверки сохраняется обезличенный запрос, реально
   отправленный модели.
3. **Решение.** Точные сроки, обещания, задачи и поля проверяются кодом; смысл
   переписки и звонков — моделью через Codex CLI по подписке. Модель получает
   только обезличенную хронологию и стандарт, возвращает строгий JSON: номер
   существующего пункта, суть, источник, время и ссылку на событие. Контролёр
   принимает лишь подтверждённые нарушения, объединяет дубли одной причины и
   не считает честный проигрыш ошибкой менеджера.
4. **Запись в CRM.** Из локальных исходных событий восстанавливаются точные
   цитаты. Контролёр формирует заданный текст `АУДИТ SOL`, находит в сделке
   прежнее примечание SOL и обновляет его; если его нет — создаёт одно. Другие
   сущности и чужие примечания не изменяет.
5. **Результаты.** Для полного прогона рядом с программой создаются список
   нарушений (одна строка на пункт), письмо РОПу и ответы на три вопроса;
   агрегаты считаются только из этого списка. Ограниченный прогон меняет только
   выбранные сделки.
6. **Запуск.** Одна команда с перечнем меток: `./run.sh D-09` или
   `./run.sh D-17 D-33 D-40 D-12 D-24`; полный запуск — `./run.sh --all`.
   Перед записью контролёр проверяет, что каждая найденная сделка относится к
   заданной воронке.
7. **Расход.** Запуск модели идёт в JSON-режиме Codex CLI. Контролёр суммирует
   фактические `input_tokens`/`output_tokens` из событий завершения, считает
   вызовы и секунды, берёт точное имя реально выбранной модели и перезаписывает
   `расход.json`, затем печатает ту же JSON-строку. Поле `как` — `подписка`.
