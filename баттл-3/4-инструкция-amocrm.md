# Инструкция: тестовый amoCRM для стенда

Пять минут. **Только чистая песочница** — рабочий аккаунт с живыми
клиентами использовать нельзя ни в каком виде.

## 1. Аккаунт

Зарегистрировать пробный на amocrm.ru (14 дней бесплатно) — этого хватит
на съёмку. Запомнить поддомен: `мойаккаунт.amocrm.ru`.

## 2. Воронка для стенда

CRM → Сделки → создать новую воронку, назвать например «AI-Баттл».
Номер воронки виден в адресной строке при переключении на неё.

## 3. Интеграция и токен

Настройки → Интеграции → «Создать интеграцию» → внешняя.
- название любое, redirect можно любой (он не используется);
- права: сделки, контакты, примечания — на чтение и запись;
- после сохранения открыть интеграцию → вкладка «Ключи и доступы» →
  **долгосрочный токен**. Скопировать целиком.

## 4. Три строки доступа

Три строки:
```
поддомен: мойаккаунт
номер воронки: 1234567
токен: eyJ0eXAiOiJKV1Qi...
```
Положите их в `env.sh` рядом со скриптами стенда (в репозиторий файл не
кладите) и проверьте доступ: `python3 amo.py --check`.

**Токен — ключ ко всей CRM. В кадр не показывать, в чат посторонним не
пересылать.** Если засветился — удалить интеграцию и создать новую.
