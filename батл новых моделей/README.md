# Батл новых моделей

Шесть моделей получили одно и то же ТЗ и собрали по нему браузерную 3D-игру Hungry Fish: аркаду про маленькую рыбу, которая ест добычу, растёт и в конце проглатывает военный крейсер. Эталон — игра, по которой написано ТЗ.

## ТЗ

| Файл | Что внутри |
|---|---|
| [`GAME_DESCRIPTION.md`](GAME_DESCRIPTION.md) | описание игры Hungry Fish: правила, управление, рост и улучшения, добыча и противники, крейсер, сундуки, интерфейс, звук, рекорд, точные формулы баланса |
| [`WORLD_QUALITY_v2.md`](WORLD_QUALITY_v2.md) | требования к игровому миру: стартовый кадр в цифрах, туман, свет и палитра, размеры и плотность декора, камера, отладочный интерфейс, приёмка по скриншотам |
