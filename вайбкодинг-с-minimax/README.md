# Вайбкодинг с MiniMax

MiniMax M3.1 Flash собрала по ТЗ браузерную 3D-игру Hungry Fish: аркаду про маленькую рыбу, которая ест добычу, растёт и в конце проглатывает военный крейсер. Эталон — игра, по которой написано ТЗ.

## ТЗ

| Файл | Что внутри |
|---|---|
| [`GAME_DESCRIPTION.md`](GAME_DESCRIPTION.md) | описание игры Hungry Fish: правила, управление, рост и улучшения, добыча и противники, крейсер, сундуки, интерфейс, звук, рекорд, точные формулы баланса |
| [`WORLD_QUALITY.md`](WORLD_QUALITY.md) | требования к игровому миру: стартовый кадр в цифрах, туман, свет и палитра, размеры и плотность декора, камера, отладочный интерфейс, приёмка по скриншотам |
| [`PROMPT.md`](PROMPT.md) | промпт, который получила модель; вместо `{PROJECT}` подставлялось имя проекта |
